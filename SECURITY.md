# Security policy

## Supported versions

Only the latest major release line receives security fixes. Upgrade to it before you report a problem in an older line.

## Reporting a vulnerability

Report vulnerabilities privately with the "Report a vulnerability" form on the repository's Security tab: https://github.com/e0ipso/schema-forms-php/security/advisories/new

Do not file a vulnerability as a public issue or pull request, and do not discuss it in public until a fix is released.

Include the affected version, the schema and UI schema that trigger the problem, and the impact you expect. This project makes no commitment on response time.
